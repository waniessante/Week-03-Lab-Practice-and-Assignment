# Object-Oriented Programming - Module 02 Lab Assignment

This repository contains my submission for the **Week 03 / Module 2 Lab Practice & Assignment**. The focus of this module is working with mathematical and geometrical objects in Java using fundamental Object-Oriented Programming concepts like constructors, method overloading, copy constructors, and object manipulation.
